# Getting started

## 1. Open WittyReader

WittyReader runs in a web browser:

- **Your own copy:** open its address (see [Hosting and building](Hosting-and-building)).
- **During development:** run `npm run dev` and open `http://localhost:5180`.

Use a current browser: Edge, Chrome, Firefox or Safari.

## 2. Install it (optional)

Installing gives WittyReader its own window and icon, and lets your system open books with it:

- **Edge or Chrome:** the install icon in the address bar, or **⋯ → Apps → Install WittyReader**.
- **Safari on iPhone or iPad:** **Share → Add to Home Screen**.
- **Android:** **⋮ → Install app**.

Once installed (in Edge or Chrome on a computer), `.epub`, `.pdf` and `.cbz` files can be opened
with WittyReader from your file manager's **Open with** menu.

## 3. Add a book

Any of these work:

- **Open…** at the top, or **Ctrl+O**, then pick one or more files.
- **Drag files** from your desktop or file manager onto the window.
- **Open with → WittyReader** from your system, once installed.

A single new book opens straight away. Several are added to your library together. Adding a book
you already have just finds it.

## 4. Read

- **Moving:**
  - **Books:** tap or click the right edge, or press →. Tap the middle for the menus.
  - **PDFs:** scroll.
  - **Comics:** tap the side you read towards.
- **Highlighting:** select text and pick a colour.
- **Writing:** with a pen, just write. With a finger or mouse, press **✎** first.
- **Back to the library:** the back arrow, **Esc**, or your browser's or phone's Back button.
  Your place is saved.

[Reading](Reading) has the full tour of each kind of book.
