A UI is the layout, shapes and finish. A theme is colour. They are chosen separately.
Each UI ships with a default theme, the same one every time (Lumen: Witty, Rail: Cinema, Stage: Midnight, Aero: Aero Day, Classic Cable: Cable blue). Any UI can wear any theme. Imported themes work in every UI, and an administrator can require one.
