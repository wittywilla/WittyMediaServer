# Keyboard shortcuts

| Key | Action |
|---|---|
| **→**, **Space**, **Page Down** | Next page |
| **←**, **Page Up** | Previous page |
| **b** | Bookmark this page (again to remove) |
| **/** | Search the book |
| **p** | Open or close the handwriting tools |
| **e** | Eraser (while the handwriting tools are open) |
| **Ctrl+Z** | Undo |
| **Ctrl+Y**, **Ctrl+Shift+Z** | Redo |
| **Esc** | In order: closes an open panel or pop-up, then the handwriting tools, then the book |

Keys work whether the focus is on the page or on the reader around it. They're ignored while you
type in a box such as the search field or a note. TV remotes' Back button acts like **Esc**.
