# Getting around

## Contents and pages

The **Contents and pages** button (📖) opens a panel with two tabs:

- **Contents:** the document's own outline, with sections nested under chapters. Choosing an
  entry jumps to the exact spot it points to, not just its page. Some PDFs have no outline; use
  **Pages** for those.
- **Pages:** a grid of page thumbnails, with the current page marked. Thumbnails are drawn as
  they come into view, so long documents open the list quickly.

## Search

Search with the 🔍 button, **/**, or **Search** on a selection. Notes:

- Searches the text of every page, ignoring upper and lower case.
- Results show the page and the words around each match, up to 300 matches.
- In long documents, results appear while the rest is still being searched.
- Choosing a result goes to that page and briefly marks the text containing the match.

## Moving through pages

| How | What it does |
|---|---|
| Scroll, swipe, the scroll bar | Move through the pages freely. |
| **Page Down**, **Space** / **Page Up** | Down or up by a screen. |
| **‹ ›** in the footer | Previous or next page (or row, with two pages across). |
| **→** / **←** | Next or previous page, when zoomed to fit the page or a set zoom (at fit width they leave the arrows to scrolling). |
| **Home** / **End** | First or last page. |
| The page slider | Drag to any page. |
| The page box | Type a page number and press Enter. |

## Resuming

Your place (the page and how far down it) is saved as you read. The document reopens exactly
there, even at a different zoom or on another device (in WittyMediaServer, where it's saved to
your account).

## Keyboard shortcuts

| Key | Action |
|---|---|
| **Page Down**, **Space** | Down a screen |
| **Page Up** | Up a screen |
| **→** / **←** | Next or previous page (not at fit width) |
| **Home** / **End** | First or last page |
| **+** / **−** | Zoom in or out |
| **Ctrl+=** / **Ctrl+−** / **Ctrl+0** | Zoom in, zoom out, fit width |
| **b** | Bookmark this page (again to remove) |
| **/** | Search |
| **p** | Open or close the handwriting tools |
| **e** | Eraser (while the handwriting tools are open) |
| **Ctrl+Z** / **Ctrl+Y** | Undo / redo |
| **Esc** | Closes an open panel or pop-up, then the handwriting tools, then the document |

Keys are ignored while you type in a box such as search or a note.
